# YOUNG · Typora 主题

适合简体中文写作的浅色与深色主题，灵感来自 [YOUNG 个人主页](https://ziyanlo.github.io/personal-site/)。细明体中文、Courier New 英文、窄栏与留白，使用柔和灰阶配色。

| 主题 | 背景 | 正文 |
| --- | --- | --- |
| Young Light | `#dededb` | `#454542` |
| Young Dark | `#242423` | `#bcbcb6` |

## 安装

1. 下载本仓库（Code → Download ZIP）并解压。
2. 在 Typora 中打开“设置 → 外观 → 打开主题文件夹”。
3. 复制 `young-light.css` 和 `young-dark.css` 到主题文件夹最外层。
4. 重启 Typora，在“主题”菜单选择 Young Light 或 Young Dark。

英文优先使用 Courier New，中文优先使用细明体（MingLiU）。字体文件未随主题提供；本机未安装时会使用后备字体。简体中文内容不会自动转换为繁体。

## 预览

下载后在浏览器打开 [主题预览.html](主题预览.html)，可切换浅色和深色。用 Typora 打开 [排版示例.md](排版示例.md) 检查实际效果。

覆盖标题、引用、链接、代码块、表格、任务列表、目录、脚注与常用侧栏状态。打印使用白底深字。macOS 原生标题栏字体不受主题控制。

浏览器静态排版已检查；完整 Typora 编辑行为尚未逐项验证。更多设置见 [安装说明](安装说明.md)。
